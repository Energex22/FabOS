# FabOS 0.4.3 — Automatic Web Images

- Product Catalog starts a background image sync once per FabOS session.
- Only commercially verified products are automatically processed.
- When a real webpage preview is downloaded, it becomes the primary image.
- Generated catalog placeholder records and files are removed after a successful download.
- Products whose sites require login, JavaScript, or block automated requests are skipped safely.
- Manual Fetch Web Image uses the same replacement behavior.
