# FabOS 0.2.0 Dark UI

This release restyles the Windows 7-compatible Tkinter desktop shell to match
the selected dark purple FabOS dashboard direction.

Implemented:
- Fixed dark sidebar navigation
- Purple active states and primary actions
- Search/header area
- KPI metric cards
- Production overview table
- Printer status panel
- Recent activity panel
- Quick actions
- Dark sortable-table styling foundation
- Responsive layout down to 1040x680

The detailed business workflows remain milestone work and now have a permanent
visual shell to be implemented inside.
