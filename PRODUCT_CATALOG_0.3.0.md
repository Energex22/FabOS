# FabOS 0.3.0 — Product Catalog

- Imports the Top 100 catalog automatically on the first run of a new database.
- Search and filter by category and commercial-license status.
- Sort every product column by clicking its heading.
- Add, edit and delete products.
- Product dossier with Overview, Images, Files and Variants tabs.
- Open the official source model page.
- Preview bundled PNG catalog cards.
- Keeps the selected dark-purple Windows 7-compatible interface.
