# FabOS Alpha 0.7.0 Complete

Implemented together: versioned Design Vault, immutable file copies, duplicate hashing, STL dimensions/triangle metadata, Anycubic Vyper build-volume checking, per-design PrusaSlicer profiles, G-code time/filament extraction, OctoPrint API service, manufacturing learning, QC inspections, and versioned database migrations with pre-migration backup. Existing 0.6.1 quote archive behavior remains.

The OctoPrint service supports job status and job commands at the core/API layer; live printer acceptance requires your actual OctoPrint URL/API key. Windows 7 should remain on a trusted LAN and should not be directly internet-exposed.
