# FabOS 0.4.1 Table Text Fix

- Forces white foreground text on both default and named ttk Treeview styles.
- Forces white selected-row text and dark row backgrounds for all widget states.
- Forces white table-heading text and purple hover states.
- Adds explicit per-row fallback tags so Windows 7 system themes cannot revert body text to black.
- Applies the fix to Dashboard, Product Catalog, Customers, detail-history tables, and placeholder module tables.
