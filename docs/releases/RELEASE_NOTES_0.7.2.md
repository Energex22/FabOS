# FabOS Alpha 0.7.2 — Design Vault Workspace

## Design Vault improvements
- Searchable Design Vault.
- Five dossier tabs: Overview, Files, Versions, Print Profile and History.
- Built-in offline STL wireframe preview using actual STL geometry.
- Anycubic Vyper 245 × 245 × 260 mm fit result.
- STL dimensions and triangle count.
- Double-click files to open them.
- File-size display and SHA-256 duplicate protection remain enabled.
- Complete version list.
- Manufacturing profile display/editing.
- Product-linked print-job history with estimated vs actual time.
- Direct "Open Design Vault" action from the Product Dossier.

## Upgrade behavior
This release continues using the same `WireVault FabOS Data` directory. Existing
products, customers, quotes, orders, Design Vault files and production history are preserved.
