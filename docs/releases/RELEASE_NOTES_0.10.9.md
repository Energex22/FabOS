# FabOS Alpha 0.10.9 — Customer Updates

## Customer Communication
- Customer Update button directly on Orders.
- New Customer Updates tab inside the Order Workspace.
- FabOS suggests the most relevant update based on the live order state.
- Built-in templates for:
  - Order received
  - In production
  - Printing
  - QC passed
  - Invoice ready
  - Payment received
  - Ready for pickup
  - Shipped
  - Delivered
  - Picked up
  - Cancelled
- Shipping messages automatically include carrier and tracking when available.
- Invoice messages automatically include the current balance.

## Sending / logging
- Copy & Log Sent copies the message to the Windows clipboard and records it in FabOS.
- Email opens the customer's saved email address in the default Windows mail client with subject/body prefilled.
- Save Draft keeps a message without marking it sent.
- Recent customer communication appears inside the selected order dossier.

FabOS does not silently send customer messages. External sending remains an explicit user action.
