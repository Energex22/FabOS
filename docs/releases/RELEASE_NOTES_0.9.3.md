# FabOS Alpha 0.9.3 — Workspace Navigation

The crowded sidebar has been replaced with six permanent workspaces:

- Dashboard
- Catalog
- Business
- Production
- Inventory
- System

## Workspace tabs

Catalog: Products, Design Vault

Business: Customers, Quotes, Orders, Invoices, Analytics

Production: Production, Printers, QC

Inventory: Filament

System: Settings, Automation, Plugins

This avoids a sidebar scrollbar while preserving every existing page. Analytics
and Invoices now live together inside Business, as requested.

No database schema changes are required for this release.
