# Product Requirements
FabOS is an offline-first manufacturing operating system for a small fabrication shop, initially an Anycubic Vyper with PrusaSlicer and OctoPrint.

## Required outcomes
- Traceable product files and commercial-license status.
- Quote to order to print job without duplicate entry.
- Automatic status, time, filament and learning from OctoPrint/G-code.
- Reproducible manufacturing record for every completed job.
- Inventory and maintenance driven by real events.
- Recoverable actions, audit records and tested backups.

## Definition of done
Clean Windows 7 install; one-week shop trial without data loss; end-to-end quote-to-paid-order test; OctoPrint reconnect and duplicate-completion tests; backup restore drill; complete user manual.
