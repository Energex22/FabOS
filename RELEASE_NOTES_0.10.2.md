# FabOS Alpha 0.10.2 — UX & QC Polish

## Quality Control
- Sort QC by Order, Customer, Product, Status or Created date.
- Search QC records.
- Filter by Pending, Rework or Passed.
- Inspection dialog is now fully editable.
- Rename checklist steps.
- Add inspection steps.
- Remove inspection steps.
- Check/uncheck items.
- Edit and preserve notes.
- Mark Needs Rework.
- Save an unfinished inspection.
- Pass QC only after all remaining checklist steps are checked.
- Status colors distinguish Pending, Rework and Passed.

## Dashboard
- KPI cards are clickable navigation shortcuts.
- Production Overview opens Production.
- Printer Status opens Printers.
- Existing Quick Actions remain available.
- Pointer cursor and dashboard hint make clickable areas clearer.

## Catalog
- Product list reduced from nine visible columns to five:
  Product, Category, Price, Print Time and License.
- SKU, designer, license details, filament usage, images, files and variants stay in the right-side dossier.
- Horizontal product-table scrollbar removed.
- Split-pane minimum widths reduced for common Windows 7 screen sizes.
- Toolbar simplified to Print, Add Product, Edit and More.
- More menu contains Details, Preview, Images, Design Vault, Source and Delete.
- Right-click product context menu added.
- Sorting remains available from every visible product heading.

This release is focused on screen fit, discoverability and reducing visual clutter.
Existing FabOS data is preserved.
