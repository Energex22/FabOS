# FabOS Alpha 0.11.2 — Global Search & Dashboard Workflow

## Global Search is now real
The search box in the top header searches:
- Products by name, SKU, category and designer.
- Customers by name, email and phone.
- Quotes by quote number, customer and notes.
- Orders by order number and customer.
- Invoices by invoice number, order and customer.
- Production jobs by job/product/printer.
- Printers by name/model.
- Filament by brand, material and color.

Search results open in one compact results window. Double-click or Open Selected jumps to the correct FabOS page and attempts to select the matching record.

## + New is now a menu
Instead of always opening a quote, the global + New button now offers:
- New Quote
- New Customer
- Add Product
- Add Filament
- Schedule/View Production
- View Printers

## Dashboard cleanup
- Open Orders now counts active orders instead of completed/cancelled history.
- Low Filament uses the threshold configured in System Settings.
- The dashboard displays that configured threshold instead of hard-coded 250 g.
- Backup quick action opens the full Backup & Health Center.
- Automatic-backup wording reflects the current daily + shutdown behavior.

This release focuses on reducing clicks and making the desktop shell useful as the central launcher for the whole shop.
